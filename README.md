# Christmas Card Exchange

A whimsical Advent-style Christmas card app inspired by the playful Google-style holiday calendar.

## Features

- 24 festive advent doors
- interactive card modal with warm holiday messages
- custom card composer to send a card to someone
- local storage persistence in the browser
- colorful winter scene with a soft, playful design

## Run locally

Open `index.html` directly in a browser, or serve it from a local web server:

```bash
cd /path/to/christmas-card-advent
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This version is intentionally lightweight and dependency-free so you can quickly open and experiment with it.
